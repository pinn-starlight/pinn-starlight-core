## 请分别看什么

### 学长

必读：[技术事实交接单](./02_实现与交接/技术事实交接单.md)和[论文实验计划](./03_实验/论文实验计划.md)。公式有疑问时再看[光污染物理约束的构造](./01_数学与方法/光污染方程简化步骤.md)。

希望重点确认：

1. screened Poisson 和结构化 $I_{city}$ 的定位是否足够谨慎，是否需要补边界损失；
2. `FFT-Gaussian / U-Net-small / PINN` 的比较是否公平且足够；
3. `DataOnly / CenterFixed / BrightInitFixed / BrightInitLearnable` 是否能验证 PDE 和可学习中心的作用。

### 文字负责同学

必读：[技术事实交接单](./02_实现与交接/技术事实交接单.md)。搭论文结构时再看[论文内容参考结构](./04_写作参考/论文内容参考结构.md)，写实验部分时查[论文实验计划](./03_实验/论文实验计划.md)。

希望重点确认：

1. 方法的一句话说明是否清楚，还有哪些术语需要解释；
2. 哪些事实可先写进摘要和方法，哪些句子必须等待实验；
3. Introduction、Related Work 和 Method 还缺哪些技术素材。

两份数学文档均为按需查阅，不要求第一次通读。
