## 1. 方法定义

输入一张归一化灰度星空观测图，以像素坐标训练 MLP，估计连续光污染背景 $\widehat I_{bg}$。screened Poisson 残差提供平滑与空间结构先验，结构化 $I_{city}$ 表示单个主要光污染源。背景扣除残差为

$$
\widehat I_{star}=I_{obs}-\widehat I_{bg}.
$$

$\widehat I_{star}$ 是沿用当前代码和推导的残差符号，不表示算法已经完成一般性的天体信号分离。

## 2. 当前技术事实

| 项目 | 事实 |
| --- | --- |
| 观测模型 | $I_{obs}=I_{star}+I_{bg}$ |
| 网络输入/输出 | $(x,y)\in[-1,1]^2$；输出单通道背景 $\widehat I_{bg}$，不是总观测亮度 |
| 候选网络 | `2 -> 128 -> 128 -> 1`，隐藏层 `Tanh`，线性输出；最终由 E1 锁定 |
| 数据损失 | $\mathcal L_{data}=\operatorname{MSE}(\widehat I_{bg},I_{obs})$ |
| PDE | $\nabla^2\widehat I_{bg}-\alpha\widehat I_{bg}+I_{city}=0$ |
| 物理/总损失 | PDE 残差 MSE；$\mathcal L=\mathcal L_{data}+\lambda\mathcal L_{physics}$ |
| $I_{city}$ | 带中心、横纵尺度和方向的单源椭圆包络；中心由模糊后的低频亮区初始化 |
| 求导与优化 | PyTorch `autograd` 计算二阶导数；Adam 优化网络和源项参数 |
| 预处理 | 线性 RGB 转灰度并下采样；正式比较必须统一预处理 |

公式推导见[数学与方法](../01_数学与方法/README.md)，完整执行协议见[论文实验计划](../03_实验/论文实验计划.md)。

## 3. 必须说明的限制

- 单图中气辉、银河、薄云、暗角等平滑结构可能与光污染混淆，不能保证严格分离。
- 数据 MSE 直接逼近混合观测，可能吸收部分星光；PDE 只能抑制，不能从理论上完全避免。
- 当前没有独立边界条件或边界损失，不能写成“施加了边界约束”。
- PDE 是物理启发正则，不是完整三维大气辐射传输方程。
- 单个椭圆源项不能完整表达多光源、复杂天际线或薄云。
- 真实图没有可靠背景真值，不报告真实图 PSNR/SSIM，也不宣称“恢复不可见星光”。

## 4. 已确定的实验方向

- 主对比：FFT-Gaussian、U-Net-small、PINN；U-Net-small 是唯一学习型 baseline。
- 正式实验固定 $\alpha=0.5$，不把可学习 $\alpha$ 作为贡献。
- 消融：DataOnly、CenterFixed、BrightInitFixed、BrightInitLearnable。
- 合成数据保存 `clean`、`background`、`observed`、星点参数和真实源中心。
- 真实图统一展示观测图、估计背景和残差，不使用无真值的全参考指标。

## 7. 写作边界

可以写：目前构建了一个用坐标 MLP、screened Poisson 残差和结构化源项估计单图光污染背景的物理约束原型，后续将与 FFT-Gaussian 和 U-Net-small 统一评估。

实验完成前不能写：显著优于其他方法、恢复不可见星光、严格求解大气方程、准确估计物理参数、可学习中心提高性能，或任何尚未运行得到的数值。
