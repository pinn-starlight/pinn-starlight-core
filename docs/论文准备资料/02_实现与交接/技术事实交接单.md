## 1. 一句话方法定义

输入一张归一化灰度星空观测图，以像素坐标为输入训练坐标 MLP，估计连续光污染背景 $\widehat I_{bg}$；以 screened Poisson 残差作为平滑和空间结构先验，并用结构化 $I_{city}$ 表示单个主要光污染源。星光残差按 $\widehat I_{star}=I_{obs}-\widehat I_{bg}$ 计算。

## 2. 已确认的技术事实

| 项目 | 当前事实 | 论文可用表述 |
| --- | --- | --- |
| 观测模型 | $I_{obs}=I_{star}+I_{bg}$ | 将观测近似分解为天体信号与光污染背景之和 |
| 网络输入 | 归一化二维坐标 $(x,y)\in[-1,1]^2$ | 网络拟合连续坐标到背景亮度的映射 |
| 网络输出 | 单通道背景估计 $\widehat I_{bg}$ | 输出不是总观测亮度，而是背景估计 |
| 当前候选网络 | `2 -> 128 -> 128 -> 1`，隐藏层 `Tanh`，线性输出 | 两层宽度为 128 的 Tanh MLP 是当前候选，最终以 E1 锁定配置为准 |
| 数据损失 | $\mathcal L_{data}=\operatorname{MSE}(\widehat I_{bg},I_{obs})$ | 数据项采用均方误差 |
| 物理方程 | $\nabla^2\widehat I_{bg}-\alpha\widehat I_{bg}+I_{city}=0$ | 使用 screened Poisson 形式的物理启发正则 |
| 物理损失 | PDE 残差的均方误差 | 通过自动微分计算二阶拉普拉斯残差 |
| 总损失 | $\mathcal L=\mathcal L_{data}+\lambda\mathcal L_{physics}$ | 数据拟合与物理正则联合优化 |
| 结构化源项 | 中心 $(x_c,y_c)$、尺度 $(\sigma_x,\sigma_y)$、方向 $\vartheta$ 的单源椭圆包络 | 源项是低维结构化先验，不是城市灯光的直接测量 |
| 中心初始化 | 对灰度图高斯模糊后，根据高亮区域估计 | 从输入图像的低频亮区初始化 |
| 自动微分 | PyTorch `autograd` 对坐标求一阶和二阶导数 | 无需手写离散拉普拉斯的反向传播 |
| 优化器 | Adam | 使用 Adam 联合优化网络与源项参数 |
| 图像处理 | 线性 RGB 转灰度后，横纵各隔一个像素下采样 | 正式实验中必须对所有方法统一预处理 |

## 3. 已确认的限制

| 限制 | 必须如实说明 |
| --- | --- |
| 单图可辨识性 | 气辉、银河、薄云、暗角等平滑结构可能与光污染混淆，不能保证严格分离 |
| 数据项竞争 | MSE 直接逼近混合观测 $I_{obs}$，可能吸收部分星光；PDE 只能抑制而不能理论保证避免 |
| 边界条件 | 当前代码没有独立边界条件或边界损失，不能写成“施加了边界约束” |
| 物理含义 | 当前 PDE 是物理启发正则，不是完整三维大气辐射传输方程 |
| 单源模型 | 单个椭圆源项不能完整表达多光源、复杂天际线或薄云 |
| 真实图评价 | 真实图没有可靠背景真值，不报告真实图 PSNR、SSIM 或“恢复不可见星光” |

## 7. 摘要和结论禁区

以下表述在没有对应实验结果前禁止使用：

- “显著优于” FFT、U-Net 或任何方法；
- “恢复了不可见星光”或“提高了极限星等”；
- “严格求解”大气辐射传输方程；
- “物理参数 $\alpha$ 被准确估计”；
- “可学习中心提高了性能”；
- 任何未实际运行得出的 PSNR、SSIM、F1、耗时或星点保留比例。

当前可以安全使用的表述：

> 本研究构建了一个用于单图光污染背景估计的物理约束原型。该原型以坐标 MLP 表示连续背景，以 screened Poisson 残差和结构化源项提供空间先验；其实际性能将通过合成数据、传统频域方法和监督式 U-Net 基线进行统一评估。
