# 论文实验计划

更新时间：2026-08-12

## 1. 实验目标

本文将方法定位为**物理启发的单图光污染背景分离方法**。网络以像素坐标为输入，估计平滑光污染背景 $\widehat I_{bg}$；天体残差由

$$
\widehat I_{star}=I_{obs}-\widehat I_{bg}
$$

得到。当前 PDE 是背景平滑性与空间结构先验，不将 $\alpha$ 解释为严格的大气物理常数。

正式实验只回答三个问题：

1. 相比 FFT-Gaussian 和任务匹配的监督式 U-Net-small，PINN 对合成光污染背景的估计和星点保留效果如何？
2. PDE 约束与可学习光污染源中心是否有助于估计偏心、椭圆光污染背景？
3. 在无真实背景参考图的真实星空图像上，各方法会产生怎样的背景图、残差图和典型伪影？

PI-AstroDeconv 属于已知 PSF 的天文去卷积，观测模型为 $I_{blur}=I_{latent}*h$，与本文的加性背景模型 $I_{obs}=I_{star}+I_{bg}$ 不同，因此不作为本论文的 baseline 或复现实验。可学习 $\alpha$ 不作为核心贡献；所有正式实验固定 $\alpha=0.5$。

## 2. 总体实验结构

| 阶段 | 内容 | 目的 | 是否进入论文主结果 |
|---|---|---|---|
| E0 | 统一流程测试 | 确认数据、训练、评估和保存链路可运行 | 否 |
| E1 | PINN 配置锁定 | 选择网络结构、物理权重、源项初始化尺度和训练步数 | 是，参数分析 |
| E2 | 合成数据对比 | FFT-Gaussian、U-Net-small、PINN 定量比较 | 是，主表 |
| E3 | 源点中心最小消融 | 验证 PDE、亮区初始化和可学习中心的作用 | 是，消融表 |
| E4 | 真实图像对比 | 固定配置下展示背景与残差 | 是，主图 |

执行顺序固定为 `E0 -> E1 -> E2 -> E3 -> E4`。E1 结束后锁定所有 PINN 超参数；不得根据 E2、E3 或 E4 的测试结果继续调参。

## 3. 统一实验协议

### 3.1 合成数据

合成数据必须同时保存：

- 干净星图 `clean`；
- 光污染背景 `background`；
- 污染观测图 `observed = clean + background + noise`；
- 真实光污染源中心、尺度、方向和星点参数；
- 随机种子。

至少构造三类背景：

1. 单中心径向光晕；
2. 偏心或椭圆光晕；
3. 多光源或非均匀平滑背景。

每类背景使用多组强度、尺度和噪声水平。数据在生成前固定划分为训练、验证、测试集，推荐比例为 `60% / 20% / 20%`。同一基础星图的不同污染版本只能出现在同一划分，防止泄漏。

U-Net-small 只使用训练集学习；FFT 参数和 PINN 配置只使用验证集选择；测试集只运行一次并生成最终结果。

### 3.2 真实数据

主图固定为 `data/image/f7.5.tif`。条件允许时，预先固定两张补充图像：一张光污染较强，一张背景结构较复杂。不得根据输出效果临时替换图像。

真实图没有背景真值，仅用于定性对照和无参考统计；不得把训练 loss 或输入重建误差写成真实去光污染精度。

### 3.3 预处理与输出

所有方法必须使用同一份线性灰度输入：

- 强度归一化到 `[0, 1]`；
- 使用相同下采样尺寸；
- 不为某一种方法单独裁剪有利区域；
- 输出尺寸与输入一致。

统一定义：

```text
observed   = 污染观测图
background = 估计的光污染背景
clean      = observed - background
```

保存用于计算指标的浮点数组；PNG 只用于展示，不得从 PNG 反读后计算指标。

### 3.4 固定运行条件

| 项目 | 规定 |
|---|---|
| 随机种子 | `20260728`、`20260729`、`20260730` |
| PINN 网络 | E1 结束后锁定 |
| PINN batch size | `8192` |
| PINN 模型学习率 | `1e-3` |
| PINN `I_city` 学习率 | `1e-3` |
| `alpha` | 固定 `0.5` |
| 初步训练步数 | `3000` |
| 最终训练步数 | E1 根据验证曲线确定后锁定 |
| 硬件记录 | CPU/GPU、内存或显存、PyTorch 与 CUDA 版本 |

开发阶段可用一个种子筛选配置；进入 E2 和 E3 表格的结果至少运行三个随机种子，报告均值与标准差。

### 3.5 输出目录

```text
experiments/outputs/
  e0_smoke/
  e1_tuning/<config>/<seed>/
  e2_synthetic/<method>/<seed>/
  e3_ablation/<variant>/<seed>/
  e4_real/<image>/<method>/
```

每次运行至少保存：

- `config.json`：配置、随机种子和代码 commit；
- `metrics.csv`：逐图指标；
- `summary.json`：均值、标准差、运行时间和硬件信息；
- `observed.png`、`background.png`、`clean.png`；
- U-Net checkpoint；
- PINN 的总损失、物理损失、`sigma_x`、`sigma_y` 曲线，以及源点中心轨迹。

## 4. E0：统一流程测试

E0 只验证流程，不用于选择方法或报告性能。

1. 从合成数据取两张图，从真实数据取 `f7.5.tif` 的固定裁剪。
2. FFT-Gaussian、U-Net-small 和 PINN 均完成一次最短运行。
3. 检查输入、背景和残差图的尺寸、数值范围与保存路径。
4. 检查 loss、指标和参数中没有 `NaN` 或无穷大。
5. 检查配置、指标、图片和 checkpoint 均能保存并再次读取。

E0 未通过时，不开始正式实验。

## 5. E1：PINN 配置锁定

### 5.1 原则

本阶段选择最终 PINN 配置，不复原历史代码中的 bug 或接口。所有候选配置使用相同的合成训练/验证划分、Screened Poisson 符号、固定 $\alpha=0.5$ 和相同评估脚本；每次只改变表中指定变量。

按阶段逐项选择，前一阶段最优值作为后一阶段默认值，禁止完全网格搜索。

### 5.2 调参顺序

| 阶段 | 变量 | 候选值 | 其他设置 |
|---|---|---|---|
| T1 | 网络结构 | `[512]`、`[256, 64]`、`[128, 128]` | `physics_weight=0.1` |
| T2 | 物理损失权重 | `0.01`、`0.1`、`0.3`、`0.4`、`0.5` | 使用 T1 最优结构 |
| T3 | 亮区初始化尺度 `kernel_size` | `21`、`31` | 使用 T1/T2 最优值 |
| T4 | 训练步数 | `3000` 后继续到收敛 | 不重新初始化模型 |

合成验证集按以下顺序选择：背景 MAE 更低、干净星图 PSNR/SSIM 更高、星点光通量误差更低；指标接近时选择参数量更少且训练稳定的配置。

E1 结束后写入只读实验配置并锁定。真实图只用于退化检查，不能以视觉偏好推翻合成验证结果。

## 6. E2：合成数据主对比

### 6.1 对比方法

| 方法 | 类型 | 输入与输出 | 参数选择或训练方式 |
|---|---|---|---|
| FFT-Gaussian | 无训练传统方法 | 频域低通得到 `background`，高频残差得到 `clean` | 在验证集选择截止尺度 |
| U-Net-small | 监督式图像复原基线 | 输入 `observed`，预测 `background` | 在合成训练集监督训练，验证集早停 |
| PINN | 本文方法 | 坐标 MLP 逐图估计 `background` | 使用 E1 锁定配置，每张图独立优化 |

U-Net-small 是唯一学习型 baseline。它必须使用本实验的合成配对训练数据，不能使用普通去噪预训练权重冒充光污染去除模型。记录网络深度、基础通道数、参数量、训练轮数、早停规则和随机种子。

传统方法无离线训练，U-Net-small 有离线训练成本，PINN 有逐图优化成本；结果中须分开报告这些成本。

### 6.2 FFT-Gaussian 实现约定

使用二维高斯低通，避免理想低通的明显振铃：

$$
F=\operatorname{fftshift}(\operatorname{fft2}(I_{obs})),\qquad
H(u,v)=\exp\left(-\frac{u^2+v^2}{2\sigma_f^2}\right),
$$

$$
I_{background}=\operatorname{ifft2}(F\cdot H),\qquad
I_{clean}=I_{obs}-I_{background}.
$$

输入先反射 padding，输出后裁回原尺寸。候选归一化截止尺度为 `0.02、0.04、0.08、0.16`，只在验证集选择一次；测试集与真实图使用同一锁定值。

### 6.3 U-Net-small 实现约定

1. 输入输出均为单通道线性灰度图。
2. 使用相同的合成训练、验证、测试划分。
3. 训练目标使用背景 MSE；不得用测试集调学习率或早停轮数。
4. 数据增强仅允许训练集随机裁剪、翻转和旋转；验证集与测试集不增强。
5. 保存验证集最优 checkpoint，并用它一次性评估测试集。
6. 论文报告网络深度、基础通道数和参数量，不能只写笼统的 “U-Net”。

### 6.4 PINN 实现约定

1. 使用 E1 锁定的结构、物理权重、初始化尺度和训练步数。
2. `I_bg_pred` 表示背景估计，`clean = observed - I_bg_pred`。
3. 每张测试图使用三个随机种子，且不使用测试图真值早停或选择 checkpoint。
4. 数据项与 PDE 残差均使用均方误差。
5. 保留观测建模局限：数据项直接拟合混合观测 $I_{obs}$，星光分量未被显式建模。

## 7. E3：源点中心最小消融

E3 只改变 $I_{city}$ 源点中心策略；网络、物理权重、训练步数、$\alpha=0.5$、尺度参数和优化器均与 E1 锁定配置一致。

| 版本 | 源点中心 | 回答的问题 |
|---|---|---|
| DataOnly | `physics_weight=0`，无 PDE 源项 | PDE 约束是否有作用 |
| CenterFixed | PDE 生效，固定图像中心 $(0,0)$ | 无场景定位先验时是否可行 |
| BrightInitFixed | PDE 生效，模糊亮区初始化后冻结 $(x_c,y_c)$ | 亮区初始化本身是否有用 |
| BrightInitLearnable | PDE 生效，使用同一亮区初始化并学习 $(x_c,y_c)$ | 中心偏移学习是否有额外收益 |

消融使用与 E2 相同的合成测试集和三个随机种子。除背景 MAE、Clean PSNR、Star F1 和光通量误差外，在单光源与偏心背景子集中报告中心定位误差：

$$
E_{center}=\sqrt{(\widehat x_c-x_c)^2+(\widehat y_c-y_c)^2}.
$$

多光源背景中，单个中心并非完整模型，因此只报告背景与星点指标，不报告中心误差。若可学习中心没有明显收益，应如实报告，不以个例图替代总体指标。

## 8. E4：真实图像对比

每张真实图使用 E2 锁定的 FFT 参数、U-Net-small checkpoint 与 PINN 配置，生成同尺寸对照图：

```text
observed | FFT background | U-Net background | PINN background
observed | FFT clean      | U-Net clean      | PINN clean
```

固定裁剪区域并排展示，重点检查：

- 大尺度光污染梯度是否被去除；
- 星点是否被背景吸收或产生光晕；
- 银河、薄云和地景是否被误当作背景；
- 图像边缘是否出现 FFT 振铃或 PINN 漂移；
- 输出是否出现负值、过度截断或新增伪星点。

真实图只报告运行时间、背景平滑度和残差负值比例等可直接计算的统计量；不报告 PSNR/SSIM，不宣称恢复了不可见的真实星光。

## 9. 评价指标

### 9.1 合成数据

| 对象 | 指标 |
|---|---|
| `background` | MAE、RMSE、PSNR、SSIM |
| `clean` | MAE、PSNR、SSIM |
| 星点区域 | Recall、Precision、F1 |
| 星点光度 | 平均相对光通量误差 |
| E3 单光源/偏心子集 | 中心定位误差 $E_{center}$ |
| 资源 | 离线训练时间、单图时间、峰值显存、参数量 |

PSNR/SSIM 按 `[0,1]` 动态范围计算。星点检测阈值和匹配半径在验证集固定，测试阶段不得改变。

### 9.2 统计与展示

- 每个测试条件报告均值与标准差；
- 同时列出不同背景类型和污染强度的分组结果；
- 主表不只给所有图混合后的单一平均值；
- 主文案例按预先规定的规则选择，并保留失败案例；
- 不以 PINN 自身的 data loss 或 physics loss 比较不同方法。

## 11. 执行清单

1. 固定合成数据生成器、划分文件和随机种子。
2. 完成 E0，确认 FFT、U-Net-small 和 PINN 共用同一输入输出协议。
3. 运行 E1 并锁定 PINN 配置。
4. 在验证集锁定 FFT 截止尺度。
5. 训练 U-Net-small，锁定验证集最优 checkpoint。
6. 一次性运行 E2 合成测试集，生成主表。
7. 运行 E3 源点中心消融。
8. 使用所有锁定配置运行 E4 真实图对比。
9. 汇总运行环境、失败案例、均值和标准差，锁定代码 commit 与结果目录后再撰写结论。

## 12. 最小完成标准

时间不足时，最低限度完成：

1. E1 中 `[128,128]`、物理权重、亮区初始化尺度和训练步数的选择；
2. 一个固定合成测试集上的 FFT-Gaussian、U-Net-small、PINN 定量结果；
3. `f7.5.tif` 上三种方法的背景图与残差图；
4. DataOnly、BrightInitFixed、BrightInitLearnable 的最小消融；
5. 主结果表、消融表和一张真实图固定裁剪对照图。
