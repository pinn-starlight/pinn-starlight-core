# 论文实验计划

更新日期：2026-08-16

> 本文件只记录正式实验协议。方法事实见[技术事实交接单](../02_实现与交接/技术事实交接单.md)，公式推导见[数学与方法](../01_数学与方法/README.md)。

## 1. 要回答的问题

1. PINN 与 FFT-Gaussian、U-Net-small 相比，背景估计和星点保留效果如何？
2. PDE、亮区初始化和可学习源点中心分别是否有效？
3. 三种方法在真实星空图上产生什么背景、残差和典型伪影？

PI-AstroDeconv 处理已知 PSF 去卷积，与本文的加性背景分离任务不一致，因此不作为 baseline。正式实验固定 $\alpha=0.5$，不研究可学习 $\alpha$。

## 2. 实验阶段

| 阶段 | 内容 | 论文产物 |
| --- | --- | --- |
| E0 | 全流程试运行 | 不进入结果 |
| E1 | 锁定 PINN 结构、物理权重、初始化尺度和步数 | 配置选择表 |
| E2 | FFT-Gaussian、U-Net-small、PINN 合成数据比较 | 主结果表 |
| E3 | PDE 与源点中心消融 | 消融表 |
| E4 | 固定真实图对比 | 主图与失败案例 |

固定按 `E0 -> E1 -> E2 -> E3 -> E4` 执行。E1 后不得依据测试集或真实图继续调参。

## 3. 统一协议

### 3.1 数据

每个合成样本保存：

- `clean_true`：干净星图真值；
- `background_true`：光污染背景真值；
- `observed = clean_true + background_true + noise`；
- 背景源中心、尺度和方向，星点参数及随机种子。

背景至少包含单中心径向、偏心/椭圆、多光源或非均匀平滑三类，并覆盖多组强度、尺度和噪声。数据先按基础星图划分，再生成污染版本，建议训练/验证/测试为 `60% / 20% / 20%`，避免同一星图跨集合泄漏。

- U-Net-small 只在训练集学习。
- FFT 参数和 PINN 配置只在验证集选择。
- 测试集只在配置锁定后运行一次。

真实图默认包括固定主图 `data/test/native_test.tif`，以及 `data/collections/manifest.csv` 中预先标记为 `usage=e4_candidate` 的真实候选图；来源未审核的 `review_source` 图不自动纳入。真实图没有背景真值，只做定性对照和可直接计算的无参考统计。运行前由 manifest 固定图像清单，不按结果临时替换。

当前 `clean_true` 来自低光害或堆栈基础图，并没有外部星表标注。星点指标统一使用数据生成时从 `clean_true` 提取并写入 metadata 的局部对比极大值作为参考；阈值固定为 `0.03`，匹配半径固定为 3 像素。论文中应称为“干净参考图星点”，不能宣称为星表真值。

### 3.2 预处理、命名与保存

所有方法使用同一线性灰度输入、归一化范围 `[0,1]`、下采样尺寸和裁剪。统一输出名称：

```text
background_pred = 估计的光污染背景
residual_pred   = observed - background_pred
```

`clean_true` 只表示合成数据真值，不能与 `residual_pred` 混用。指标从浮点数组计算，PNG 只用于展示。

每次正式运行保存：

- `config.json`：配置、随机种子和代码 commit；
- `metrics.csv` 与 `summary.json`：逐图指标、均值、标准差、耗时和硬件；
- `observed`、`background_pred`、`residual_pred` 的浮点数组和 PNG；
- U-Net checkpoint；PINN loss、源项参数曲线和中心轨迹。

建议目录：

```text
experiments/outputs/
  e0_pipeline_check/
  e1_tuning/<config>/<seed>/
  e2_synthetic/<method>/<seed>/
  e3_ablation/<variant>/<seed>/
  e4_real/<image>/<method>/
```

### 3.3 固定运行条件

| 项目 | 设置 |
| --- | --- |
| 随机种子 | `20260728`、`20260729`、`20260730` |
| PINN batch size | `8192` |
| MLP / $I_{city}$ 学习率 | 均为 `1e-3` |
| $\alpha$ | 固定 `0.5` |
| 初步步数 | `3000`；最终值由 E1 锁定 |
| 运行环境 | 记录 CPU/GPU、内存/显存、PyTorch 和 CUDA 版本 |

E1 可先用一个种子筛选；E2 和 E3 至少运行三个种子并报告均值与标准差。

## 4. 各阶段执行

### E0：试试能不能跑

每种方法只用少量数据跑几步，能正常打印 loss，并输出一张背景图和残差图即可。本阶段不比较效果，也不进入论文结果；程序能跑通后再开始后续正式实验。

### E1：PINN 配置锁定

所有候选使用相同训练/验证划分、PDE 符号和 $\alpha=0.5$，按顺序单变量选择：

| 顺序 | 变量 | 候选 |
| --- | --- | --- |
| T1 | 网络结构 | `[512]`、`[256,64]`、`[128,128]`；初始 `physics_weight=0.1` |
| T2 | `physics_weight` | `0.01`、`0.1`、`0.3`、`0.4`、`0.5` |
| T3 | 初始化 `kernel_size` | `21`、`31` |
| T4 | 训练步数 | 从 `3000` 继续至验证曲线稳定，不重新初始化 |

优先比较背景 MAE，再比较残差 PSNR/SSIM 和星点光通量误差；接近时选更小、更稳定的配置。锁定后写入只读配置。真实图只用于检查明显退化，不能参与选择。

### E2：合成数据主对比

| 方法 | 约定 |
| --- | --- |
| FFT-Gaussian | 二维高斯低通估计背景；反射 padding；在验证集从归一化尺度 `0.02/0.04/0.08/0.16` 中选一个 |
| U-Net-small | 单通道输入和背景输出；合成配对数据监督训练；背景 MSE；验证集早停；记录结构、参数量和训练轮数 |
| PINN | 每张图独立优化；使用 E1 锁定配置；数据项和 PDE 残差均用 MSE |

三者的计算范式不同，分别报告 FFT 单图时间、U-Net 离线训练与单图推理时间、PINN 单图优化时间。

### E3：最小消融

除表中变量外，网络、权重、步数、$\alpha$、尺度参数和优化器均使用 E1 锁定值。

| 版本 | 设置 | 验证内容 |
| --- | --- | --- |
| DataOnly | `physics_weight=0` | PDE 是否有作用 |
| CenterFixed | PDE 生效，中心固定 $(0,0)$ | 无定位先验的表现 |
| BrightInitFixed | 从模糊亮区初始化并冻结中心 | 初始化本身是否有用 |
| BrightInitLearnable | 相同初值，训练中学习中心 | 中心偏移是否带来额外收益 |

只在单光源、偏心背景子集报告

$$
E_{center}=\sqrt{(\widehat x_c-x_c)^2+(\widehat y_c-y_c)^2}.
$$

多光源不报告单一中心误差。若可学习中心无收益，应如实报告。

### E4：真实图对比

使用 E2 锁定的 FFT 参数、U-Net checkpoint 和 PINN 配置。主图统一下采样 2 倍后默认保留整幅图；若显存不足，可固定使用 `1024 x 1024` 中心裁剪（通过 `--crop-size 1024`）：

```text
observed | FFT background | U-Net background | PINN background
observed | FFT residual   | U-Net residual   | PINN residual
```

检查大尺度梯度、星点吸收、银河/薄云/地景误判、边缘伪影、负值和新增亮点。真实图不报告 PSNR/SSIM，不宣称恢复了不可见的真实星光。
