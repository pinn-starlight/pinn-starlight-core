## 2. 可拆用的文字素材

以下内容只提供表达思路，正式写作时需改写并补引用。

### 研究背景

人工照明经大气散射形成空间缓变的夜空背景，抬高图像基线，使暗弱天体更难从背景与噪声中分辨。传统平滑、曲面拟合和频域方法运行快速，但尺度选择依赖经验，并可能把银河、星云等大尺度天体结构一并当作背景。监督式复原网络表达能力较强，但通常依赖现实中难以获得的污染/干净配对数据。

### 本文思路

本文针对单张图像优化连续背景函数，而非训练跨图像的端到端去污染模型。坐标 MLP 输出 $\widehat I_{bg}$，screened Poisson 残差与结构化 $I_{city}$ 提供空间先验，天体残差按 $I_{obs}-\widehat I_{bg}$ 得到。该 PDE 应称为物理启发正则，不能表述为完整大气散射求解器。

### 相关工作定位

- FFT-Gaussian：无需训练的传统低频背景基线。
- U-Net-small：使用合成配对数据的任务匹配监督基线。
- PINN：Raissi 等人提出以微分方程残差约束神经网络的框架；本文将这一思想用于单图背景建模。
- Garstang 夜天光模型可作为人工照明散射的理论背景，但当前二维 PDE 不是从该模型严格推导出的等价方程。

### 方法部分必须包含

1. $I_{obs}=I_{star}+I_{bg}$ 的近似观测模型；
2. 坐标 MLP 的输入、输出和最终锁定结构；
3. $\nabla^2\widehat I_{bg}-\alpha\widehat I_{bg}+I_{city}=0$；
4. $I_{city}$ 的中心、尺度、方向和初始化方式；
5. 数据 MSE、PDE 残差 MSE、损失权重和自动微分；
6. 当前未显式施加边界条件，正式实验固定 $\alpha=0.5$。

公式与符号直接从[数学与方法](../01_数学与方法/README.md)提取，不在本文件重复维护。

## 3. 实验与结果写作

实验设置只概括[论文实验计划](../03_实验/论文实验计划.md)中实际执行的版本。结果部分至少包含：

- FFT-Gaussian、U-Net-small、PINN 的合成数据主表；
- PDE 与源点中心消融表；
- 固定真实图的观测、背景和残差对照；
- 运行成本、失败案例和局限性。

真实图无可靠背景真值，因此不报告 PSNR/SSIM。不同方法的训练范式不同，应分开报告 U-Net 离线训练、U-Net 推理和 PINN 逐图优化成本。

## 4. 讨论与限制

必须讨论：

- 单图分离不可辨识，气辉、银河、薄云、暗角可能与光污染混淆；
- 数据 MSE 可能促使背景网络吸收部分星光；
- 单源椭圆 $I_{city}$ 对多光源和复杂天际线表达有限；
- 灰度输入没有利用颜色信息；
- PINN 逐图优化成本较高；
- 归一化坐标中的 $\alpha$ 是有效模型参数，不是可直接测量的大气常数。

实验结果出来前，不得写“显著优于”“恢复不可见星光”“严格求解大气方程”或“可学习中心提高性能”。
